# Example results

These files are generated by the backtest with Yahoo Finance data downloaded on
2026-07-29.

- `strategy_summary.csv`: main performance comparison;
- `latest_weights.csv`: latest target weights in the sample;
- `cumulative_growth.svg`: growth of one dollar;
- `drawdowns.svg`: portfolio drawdown history;
- `efficient_frontier.svg`: latest simulated feasible portfolio set.

Raw Yahoo Finance data is not included in this repository. Result files are
provided only to make the research output easy to review.
